**First Official Release**

Built for **Windows**, **Bolt Mod Manager** provides a safe and flexible way to import, organize, deploy, and manage modifications for virtually any game.

**Key Features:**

- **Non-Destructive Deployment**: Keeps modifications outside the game directory while preserving recoverable backups of replaced original files.
- **Universal Game Support**: Manages any Windows game by selecting its installation folder and executable.
- **Archive Importing**: Imports `.zip`, `.7z`, and `.rar` mod packages with detailed, cancelable progress reporting.
- **Profiles and Bulk Management**: Supports multiple profiles and bulk enabling, disabling, and removal of modifications.
- **Conflict Management**: Displays conflicting files and lets users define which mod loads **Before** or **After** the other.
- **Modification Editor**: Edits metadata and deployment paths through an expandable file tree without rebuilding the original archive.
- **Safe Game Control**: Launches the configured game and provides a **Stop** action for force-closing an unresponsive process.
- **Modern Interface**: Includes search, recent games, responsive controls, and polished light and dark themes.
